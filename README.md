# taxas-maquininhas-br

Taxas de entrada das maquininhas de cartão no Brasil — Ton, PagBank, Mercado Pago e InfinitePay.

Dados mantidos por **Guia Maquininha**: https://guiamaquininha.com.br/indice-de-taxas/ (conferidos todo mês nos sites oficiais das marcas).

## Arquivos
- `taxas.json` — débito, crédito à vista, Pix e 12x por marca (outubro/2026)
- `index.html` — calculadora simples de taxa e valor líquido

## Simulador completo
